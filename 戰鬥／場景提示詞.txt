# 知識之城 RPG — 戰鬥畫面／場景背景 圖資清單＋提示詞

> 格式一律：PNG、透明背景（角色）或實景背景  
> 角色／怪物建議 512×512；Boss 768×768；背景見下表  
> 統一風格前綴（角色用）：

```
cute chibi children's game character illustration, storybook watercolor style, soft thick outline, vibrant warm colors, big sparkling eyes, full body, single character, centered, plain white background, no text, no shadow
```

背景用：

```
cute children's game environment background, storybook watercolor, soft colors, no characters, no text, wide landscape
```

## 三、職業技能對應（已寫進程式，出圖可對照）

| 通用 | 勤學、財運、回復、小提示、連擊之心、寵物連結 |

## 四、戰鬥 UI 建議層級（對齊宣傳圖）

```
┌─────────────────────────────────────┐
│  標題（章節名）          [暫停]      │
│                                     │
│   [英雄立繪]    ⚔️    [怪物立繪]     │
│   HP條／名字         HP條／名字      │
│                                     │
│            COMBO 5                  │
│                                     │
│         ┌─────────────┐             │
│         │  8 + 3 = ?  │  ← 題目框   │
│         └─────────────┘             │
│     [9] [10] [11] [12]  ← 大按鈕    │
│                                     │
│   [技1] [技2] [技3] [技4]  ← 可選    │
└─────────────────────────────────────┘
```

目前程式已改為：**左英雄、右怪物** 並排，較接近宣傳圖。  
完整「草地場景＋大立繪＋底部技能圓鈕」需要上面 `bg_battle.png` 與角色／技能圖示素材後，再把 `Art.usePng = true` 即可疊圖。

## 五、建議製作順序（戰鬥優先）

**Phase Battle（立刻提升戰鬥質感）**
1. bg_battle.png  
2. hero_warrior / mage / archer / engineer / scholar（5 張）  
3. mon_m01.png（加法史萊姆）  
4. ui_combo_badge、ui_question_box、ui_opt_btn  

**Phase Map**
5. map_world_overview.png + bg_map_zone0～3  

**Phase Rest**
6. 其餘區域背景、Boss 背景、城市／寵物背景  

---

## 六、去背與匯出

1. 生成時背景用**純白**  
2. remove.bg / Photopea 去背  
3. 匯出 PNG，檔名全小寫  
4. 放到 `index.html` 旁的 `img/` 資料夾  
5. 程式內 `Art.usePng = false` 改成 `true`

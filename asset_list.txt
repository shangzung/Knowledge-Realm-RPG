# 知識之城 RPG — 最終版圖資製作清單（無列車）

## 規格（全部通用）

- 格式：**PNG，透明背景**（沒有透明背景，角色會帶著白色方框）
- 角色／怪物／寵物／Boss 尺寸：**512 × 512 像素**正方形（Boss 建議 768×768）
- 角色置中、四周留約 8% 空白、腳踩在底部
- 大小：每張建議 **300KB 以內**（可用 tinypng.com 壓縮）
- 檔名：**全小寫英文 + 數字，不要空格、不要中文**
- 資料夾：在 `index.html` 旁邊建立 `img` 資料夾，所有圖片放進去

```
你的資料夾/
├─ index.html
└─ img/
   ├─ hero_warrior.png
   ├─ mon_m01.png
   ├─ pet_p1_0.png
   ├─ bg_map_zone0.png
   └─ ...
```

**不用一次做完**：有哪張圖就換哪張，沒有的圖遊戲會自動用現有的 SVG 插圖或 emoji（Boss 用 emoji）。

---

## 統一畫風提示詞（每張都加在最前面，畫風才會一致）

```
cute chibi children's game character illustration, storybook watercolor style, soft thick outline, vibrant warm colors, big sparkling eyes, full body, single character, centered, plain white background, no text, no shadow
```

接著在後面加上角色描述，例如：
`a brave boy warrior with brown hair, blue armor, red cape, holding a sword`

去背小技巧：生成時用純白背景，再丟進 remove.bg 或 Photoshop / Photopea 去背，存成 PNG。

## 與宣傳圖對應的 UI 重點

1. 首頁：玩家頭像 + 等級 + 金幣／鑽石 + 經驗條 + 大按鈕「開始冒險」
2. 底部導覽：冒險｜地圖｜圖鑑｜寵物｜城市｜任務｜家長｜設定
3. 戰鬥：怪物在上、英雄在下、大題目框、大型選項按鈕、COMBO 顯示
4. 圖鑑：未取得顯示黑影、已取得彩色、完成度百分比
5. 家長模式：正確率、弱點分析、學習曲線
6. 整體風格：高彩度、Q 版、大型按鈕、強烈成就感、無網頁感
